# Паперовий експеримент v3

Затверджена наступна версія v2 після виправлення блокера реєстру copyability. v2 збережено без переписування: він зупинився після зміни production-коду, мав 0 угод і не створив придатних wallet-level спостережень.

Торгові правила, вхід, вихід за початковими гаманцями, 24-годинний контроль і модель витрат без змін описані в `../hyper-paper-v2/RULES.md`. Методичне уточнення v3: індивідуальна вибірка гаманця містить лише завершені епізоди, що не перекриваються; трекер обчислює односторонню 95% нижню межу та записує точну production-схему у `wallet_copyability.json`.

Запуск:

`PAPER_EXPERIMENT_DIR=hyper-paper-v3 PAPER_EXPERIMENT_VERSION=v3 python3 hyper-paper-v2/track.py`

Перший успішний запуск створює новий baseline, виключає всі наявні на той момент записи й починає нове 25-денне вікно. Будь-яка наступна зміна коду production, списку гаманців або конфігурації знову ставить набір на паузу. Трекер читає production і публічний API, але пише лише локальні артефакти та не торгує, не надсилає Telegram і не встановлює реєстр у production.
